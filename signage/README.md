# 대기·호출 사이니지

기존 /signage/ 주소로 표시합니다. 서버 변경이 포함되므로 적용할 때 서버를 재시작하고 사이니지를 새로고침하세요.

- 광고는 원본 비율을 유지해 평소 전체 화면, 최근 배정이 있으면 화면 높이 94%, 호출 시 72%로 표시합니다.
- 진찰·치료 대기 인원은 표시하지 않습니다. 최근 호출은 최대 3건을 각각 종료 후 1분 동안 표시합니다. 호출 화면은 성함·목적지·들어와 주세요를 세 줄로 중앙 정렬합니다. 성함 140px, 노란색 목적지 240px, 안내 90px로 표시합니다. 부드러운 2음 딩동 차임을 호출 시작 시 한 번 재생하고, 한 명 호출은 20초, 묶음 호출은 35초 동안 유지한 뒤 닫힙니다. 배정 후 3초 동안 모아서 1명은 하단 호출, 2~10명은 광고를 가린 전체 화면 목록으로 표시합니다. 6~10명은 두 열입니다. 전체 안내 중 추가 배정은 같은 목록에 넣고 마지막 추가 후 35초까지 유지합니다. 호출음은 묶음당 한 번입니다. 10명을 넘는 추가 배정은 다음 묶음으로 안내합니다.
- 대기실 또는 임시 대기에서 일반 베드·스파인·원장실로 입실하면 서버가 자동 호출합니다. 이미 베드·원장실에 있던 환자의 내부 이동이나 자리 교환은 호출하지 않습니다. 동일 환자의 치료·메모 수정도 재호출하지 않습니다. 수동 호출·취소·입실 버튼은 없습니다.
- 대기실의 미배정 환자와 임시 대기 환자만 집계합니다. 첫 번째 치료가 진찰이면 진찰 대기, 나머지는 치료 대기입니다. 초진·재진 및 목표 원장실 여부는 분류에 사용하지 않습니다. 이미 치료 베드·원장실에 배정된 환자는 배정 알림이 남아 있어도 제외합니다.
- 호출과 최근 배정에 전체 이름을 표시하고 베드 번호를 안내합니다. 스파인은 스파인으로 표시합니다. 원장실은 원장실 번호로 표시합니다. 7번·임시 대기 베드는 호출 대상에서 제외합니다.
- 호출음은 항상 활성화되며 켜기·끄기 버튼은 없습니다. 브라우저 자동재생이 차단되면 TV에서 한 번 클릭·터치·확인 키 입력이 필요합니다. 2음 딩동 차임이 끝난 뒤 서버 Windows PC의 한국어 음성으로 생성한 WAV를 재생합니다. LG 브라우저의 TTS 지원 여부에 의존하지 않습니다. 한 명이면 이름과 목적지를, 묶음이면 화면의 성함·배정 위치 확인 안내를 읽습니다. 숫자는 팔 번처럼 한글로 전달합니다. 서버에는 System.Speech와 한국어 음성이 필요하며, 생성 실패 시 차임과 화면 안내는 유지됩니다.
- 사용자 환경 변수 `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`을 설정하면 Azure SunHi (`ko-KR-SunHiNeural`, 속도 -5%)로 WAV를 생성합니다. 키는 서버에서만 사용하며 브라우저로 전달하지 않습니다. 이름과 안내 문구는 Azure Speech로 전송됩니다. Azure 실패 시 60초 동안 Windows Heami로 대체합니다. 설정이 없으면 처음부터 로컬 음성을 사용합니다. 환경 변수 변경 후 서버를 재시작하세요.
- 음성 생성은 비동기로 한 번에 한 건씩 실행합니다. 동일 문구 요청은 생성 중에도 공유하며, 최대 32건을 30분 동안 메모리에 보관합니다. 로컬 생성의 임시 WAV는 읽은 뒤 삭제합니다. `/signage/speech?group=호출묶음ID`는 현재 호출에 해당하는 음성만 반환합니다.
- /signage/status는 전체 표시 이름(displayName)과 집계 인원을 전달합니다. 현재 호출에는 TTS용 전체 성함(speechName)도 전달합니다. 환자키·치료 기록은 응답에 포함하지 않습니다.
- 호출 기록은 기존 암호화 app_state의 signageCalls 키에 저장됩니다. 30분 이상 지난 호출은 표시하지 않으며 최신 100건 이내로 관리합니다.
- 검증: node --test server/signage-state.test.js server/doctor-alert-sse.test.js

최근 배정이 남아 있으면 화면 높이 6%의 얇은 띠에 최대 3명을 한 줄로 표시합니다. 각 항목은 호출 종료 후 1분간 유지되며, 성함은 흰색·목적지는 노란색입니다. 호출과 최근 배정이 모두 없으면 광고를 전체 화면으로 표시합니다.
